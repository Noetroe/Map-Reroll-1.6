[h1]Map Re-Reroll (1.6)[/h1]

This is the updated RimWorld 1.6 version of Map Reroll. The original 1.4 and 1.5 content is still included for legacy players.

Map Reroll lets you quickly randomize your starting map and steam geyser locations. Your starting scenario, colonists, items, and settlement setup stay the same.

The mod includes map previews, so instead of blindly rolling random maps, you can browse preview pages and choose the map you want.

[h1]Warning[/h1]

Use your best judgment when rerolling and save your game first.

Map generation is one of RimWorld's more sensitive systems. This mod has been updated and tested around vanilla-style generation, but mods that add or change map generation may behave unexpectedly.

Compatibility update: Map Reroll only enables map and geyser rerolls on vanilla player-home settlements and its existing Setup Camp integration. Quest sites, scripted maps, and unknown custom map parents are blocked before destructive operations begin. Map Reroll records the central map-generation request and also blocks recipes that used custom extra GenSteps, a pre-content callback, pocket-map generation, or the step debugger. It classifies those transient inputs rather than consuming or reconstructing them later. The selected map is still generated through RimWorld's normal map pipeline so active mod GenSteps and MapComponents can initialize normally.

Map Reroll uses the current map size and generator for previews, retries with its fallback preview generator when Map Preview rejects a request or returns a blank result, and lets Geological Landforms participate in fallback preview generation. If you use Geological Landforms, load it after Map Reroll.
